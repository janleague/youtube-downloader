Bundled fonts
=============

YouTube Downloader bundles these variable font files:

- Sora Variable — headings and display text
- Manrope Variable — interface and body text

Both font families are distributed under the SIL Open Font License 1.1.
Their license files are included in this directory:

- OFL-Sora.txt
- OFL-Manrope.txt

Official sources:

- https://fonts.google.com/specimen/Sora
- https://fonts.google.com/specimen/Manrope

If a bundled font cannot be loaded, the application falls back to Segoe UI.
